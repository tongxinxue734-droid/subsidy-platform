# 西安市高龄补贴监管平台

全市高龄保健补贴补助发放情况 · 市级/区县/街道三级监管平台（前后端分离）。

## 技术栈

- **后端**：FastAPI + SQLAlchemy + SQLite
- **前端**：Vue 3 + Element Plus + ECharts + Vite
- **数据**：10 万条脱敏受益老人档案 + 月度发放台账 + 通知公告

## 启动方式

**1. 启动后端（端口 8000）**

```powershell
pip install -r requirements.txt
python -m uvicorn main:app --host 0.0.0.0 --port 8000
```

**2. 启动前端（端口 5173）**

```powershell
cd frontend
npm install
npm run dev
```

访问 `http://localhost:5173`。

> **首次启动提示**：首次运行后端会自动生成约 100 万条演示数据（10 万老人档案 + 年度认证记录 + 个人发放记录 + 待遇变更记录等，数据库约 100MB），需等待 1~3 分钟；数据生成幂等，之后启动秒开。

## 业务板块

1. **工作台**：待办中心（待审申领 / 待复审 / 待处理工单 / 未读消息 聚合）
2. **监管驾驶舱**：态势 KPI + 西安区县地图热力（点击下钻街道）+ 认证到期提醒 + 大屏模式
3. **补贴标准与政策**：四档标准 + 申领流程 + 资金来源 + 政策法规库 + 补贴测算器
4. **申领审核**：申领工单（街道审核 → 区县审批 → 建档）+ 新增申领登记
5. **老人档案**：老人档案（真实区划码档案号/脱敏）+ 全生命周期详情下钻 + 批量复审/停发 + 数据导出
6. **年度复审**：复审 KPI + 认证进度 + 区县复审率 + 认证方式分布 + 待复审清单
7. **发放管理**：月度台账 + 发放趋势 + 发放异常（停发/待认证复核补发）+ 导出
8. **资金监管**：财政分担 + 拨付情况 + 绩效评价（预算执行/到账及时率）
9. **智能稽核**：疑点筛查 + 分级预警 + 风险画像（风险评分/高风险清单）+ 一键生成稽核工单
10. **双随机抽查**：随机抽对象 + 随机派人员 + 抽查结果公开（发现问题转稽核工单）
11. **工单督办**：工单中心（流转销号）+ 跨部门数据比对 + 政策找人（应享未享）+ 导出
12. **统计分析**：区县 × 年龄段交叉分析 + 性别结构 + 申领渠道分布 + 老龄化趋势预测
13. **阳光公示**：各区县发放公示 + 社会监督举报 + 导出
14. **通知公告**：公告列表 + 详情（分类筛选）
15. **系统管理**：监管账号（脱敏）+ 审计日志 + 消息中心

## 智能与便捷功能

- **AI 助手**：右下角悬浮聊天，基于 DeepSeek 提供政策问答 + 平台实时数据查询（`DEEPSEEK_API_KEY` 环境变量配置）
- **全局搜索**：顶栏按 档案号 / 姓名 / 工单号 / 申领编号 检索跳转
- **数据导出**：老人档案 / 发放明细 / 工单 / 公示 一键导出 CSV（Excel 可直接打开）
- **地图下钻**：驾驶舱区县热力 → 点击下钻街道分布
- **大屏模式**：驾驶舱一键全屏

## 数据贯通

以「老人档案号」为核心主数据，串联 **申领 → 审核 → 建档 → 复审 → 发放 → 稽核 → 工单 → 变更** 全生命周期；任一老人详情页可下钻到其认证/发放/稽核/变更全轨迹。市/区县/街道三级权限贯穿所有接口，按管辖范围自动过滤。
